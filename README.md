# 🏁 Rockland Tycoon

A free property-trading board game set in **Rockland County, New York**. Buy towns from Hillburn to Nyack, ride the Pascack Valley Line and TOR bus, dodge the Bridge Toll, and try not to get busted on the Palisades Parkway.

## Play
Open the game in any web browser, on a phone or a computer. You don't need to install anything.

- 1 to 4 players: play against computer opponents, or pass the device around with friends
- Buy properties, collect rent, trade, build houses and hotels
- Rockland Adventure and Town Hall cards
- Your game saves itself automatically in your browser

## About
This is a fan-made game. It isn't affiliated with any board game company.
